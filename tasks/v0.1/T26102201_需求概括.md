## 1. 一句话目标

在现有最小 Agent 上补齐“工具可见、引用可信、评价可量化、调用链可运营”四件事：用户页展示在线工具，回答末尾展示本轮工具调用与可展开结果，搜索引用只展示真实可访问链接，支持点赞/拉踩；新增本地管理后台，按自定义时间范围查看调用链、工具成功率、满意率、模型与上下文指标，并在顶部给出异常告警。

---

## 2. 成功标准（按优先级）

1. 用户页左侧栏显示 5 个工具及在线状态；MCP 子进程离线时整体置灰并提示“工具服务离线”。
2. 每次最终回答末尾显示本轮工具汇总；纯聊天不显示；点击可展开参数、状态、耗时、重试次数、摘要与错误，完整结果按需加载。
3. 搜索引用展示在回答末尾、工具汇总下方；默认展示前 3 条可访问链接，点击展开全部；校验失败的链接折叠并标注，不作为可点击链接。
4. 用户可对最终回答点赞/拉踩；拉踩选 7 类原因，选“其他”必须填写说明；可修改、可取消；同一用户同一消息只有一条记录。
5. 管理后台支持自定义时间范围，提供总览、工具、模型、上下文、会话、评价、调用链明细与 CSV 导出，并在顶部展示异常告警。
6. 任一 turn 可在后台展开完整 trace 时间线，看到模型调用、工具调用、降级、熔断、压缩等事件及成功与否。
7. 现有测试继续通过；新增测试覆盖链接校验、引用归并、评价、后台聚合、告警、CSV。
8. 后端 ruff / mypy / pytest 通过；前端 npm ci / typecheck / build 通过；浏览器完成用户页与后台验收。

## 4. 技术栈与硬约束

| 层 | 选型 | 约束 |
|---|---|---|
| 后端 | 沿用 Python 3.11+ / FastAPI / httpx / SQLAlchemy 2.x async / PostgreSQL | 不引入新的后端框架 |
| 前端 | 沿用 Vue 3 / Vite / TypeScript / Pinia | 禁用 React 及其生态 |
| 新增前端依赖 | vue-router 4.x、echarts 5.x | ECharts 仅后台路由懒加载 |
| 工具协议 | 沿用现有手写 MCP JSON-RPC 2.0 over stdio | 不改协议、不引入 MCP SDK |
| 管理后台 | 本地不鉴权，路由 `/admin` | 后端默认仅 127.0.0.1；公网部署前必须补鉴权 |
| 时区 | DB 存 UTC，界面按 Asia/Shanghai | 日期范围、趋势、告警统一时区 |
| 数据量假设 | < 1000 轮/天 | events 保留 90 天；单次查询最大 90 天；分页 50 |
| 会话隔离 | `session_id + user_id` | 所有新接口必须带归属校验，禁止跨会话读取 |

补充约束：

- 链接校验必须防 SSRF：不得接收客户端任意 URL 让服务端请求。
- 链接校验失败不得让 `search` 工具整体失败。
- 所有新接口不得破坏现有 API、SSE 事件与数据库字段。
- 前端不得用 `v-html` 渲染用户内容、评价原因或搜索标题/摘要。
- CSV 导出必须防公式注入。
- 后台告警仅后台展示，不接外部通知。

## 6. 功能需求

### 6.1 用户页在线工具面板

- 位置：左侧栏会话列表下方，可折叠，默认展开。
- 数据：`GET /api/tools`，返回项新增 `online: bool`。
- 判定：MCP 子进程存活且 `tools/list` 成功，则 5 个工具全部在线；否则全部离线。
- 展示：工具名、简短描述（悬浮提示）、在线/离线圆点；离线整体置灰。
- 刷新：进入页面拉取一次；每 30 秒轮询一次；提供手动刷新按钮。
- MCP 离线：面板显示“工具服务离线”，不阻塞会话列表与历史浏览；发送消息沿用现有错误提示。
- 不做逐工具主动探活，不新增调用成本。

### 6.2 回答末尾工具汇总

- 触发：一个 turn 结束后，该 turn 有真实工具调用才显示；纯聊天不显示。
- 位置：最终回答气泡下方。
- 折叠态：`调用了 N 个工具 · 成功 X / 失败 Y / 禁用 Z · 总耗时 T ms`；含 `search` 时追加 `来源 L 条`。
- 展开态：按调用顺序列出每个工具：
  - 工具名、状态（ok / error / blocked）；
  - 参数 JSON（截断 500 字，敏感字段脱敏）；
  - 耗时、重试次数；
  - 结果摘要；
  - 错误原因（失败时）；
  - `artifact://` 引用与“查看完整结果”按钮。
- 完整结果：点击后调用 `GET /api/sessions/{session_id}/tool-calls/{tool_call_id}/result`，返回全文；必须校验会话归属；前端弹层展示，限制高度，可复制。
- 历史消息：加载会话时调用 `GET /api/sessions/{session_id}/tool-calls`，按 `turn_no` 分组；历史消息同样显示汇总。
- 流式过程：保留现有过程卡片；`tool_result` 到达时更新；turn 结束后生成汇总。
- 去重：按 `tool_call_id` 去重；同一 turn 多次调用同名工具分别列出。
- 失败/禁用：失败显示错误原因；blocked 显示“已禁用”，不计入成功。

### 6.3 搜索引用与链接校验

- 数据来源：`search` 工具返回的 citations：title、url、snippet。
- 归并：同一 turn 多次 `search` 合并；按 URL 去重，保留首次出现顺序；最多 10 条。
- URL 规范化：协议与域名小写；去掉 fragment；保留 query；长度上限 2048。
- 校验时机：`search` 工具内部并行校验，结果随工具返回；不延迟到 turn 结束。
- 校验方式：
  - 先 HEAD，跟随重定向；
  - HEAD 返回 400/403/405/429 或异常时，改用 GET，带 `Range: bytes=0-2048`，流式读取少量内容后关闭；
  - 单条超时 8 秒；并发上限 5；
  - 仅允许 http/https。
- 判定：最终状态码 2xx/3xx 且未超时 => `reachable=true`；401/403/404/5xx/超时/异常 => `false`。
- 安全（防 SSRF）：
  - 拒绝 localhost、127.0.0.0/8、10/8、172.16/12、192.168/16、169.254/16、::1、fc00::/7、fe80::/10；
  - 拒绝 file://、ftp://、data: 等非 http(s)；
  - DNS 解析结果落在私网地址时拒绝；
  - 跟随重定向后必须再次校验最终 URL；
  - 单次最多 10 条。
- 失败隔离：任一链接校验失败不影响 `search` 成功；返回结果带 `reachable=false`。
- 展示：
  - 位置：最终回答末尾、工具汇总下方；
  - 默认展示前 3 条 `reachable=true`；
  - 点击“展开全部”展示全部 `reachable=true`（最多 10 条）；
  - 失败链接折叠为“N 条链接未通过校验”，展开后灰色不可点击，显示状态码/原因；
  - 每条显示标题、域名、snippet（最多 2 行）、可达标识；
  - 点击新窗口打开，`rel="noopener noreferrer"`；
  - 无可用链接时显示“未获取到可访问来源”。
- 点击兜底：打开前调用 `POST /api/citations/check`，body `{citation_ids:[...]}`；服务端只允许当前 session/turn 已存的 citation id，重新校验并返回最新状态；前端 2 秒内返回则更新/放行，超时直接打开原链接。
- 缓存：同一 citation 10 分钟内不重复校验；进程内 LRU，最多 500 条。
- 持久化：citations 及 reachable/status_code/checked_at 写入 `tool_calls.result_meta`；历史直接读取。
- 链接展示字段限制：title ≤ 200 字符，snippet ≤ 300 字符；超长截断。

### 6.4 点赞 / 拉踩

- 位置：最终回答气泡底部右侧，点赞/点踩图标。
- 可评价消息：assistant 且 `meta.kind in {final, wrap_up}`；过程消息、parse_error、budget 提示不显示。
- 交互：
  - 点赞：`rating=like`；
  - 点踩：弹出原因面板；
  - 再次点击已选中的评价：取消；
  - 切换赞/踩：更新原记录。
- 原因 7 项：`irrelevant` 答非所问、`tool_error` 工具调用错误、`bad_link` 链接失效、`too_slow` 响应太慢、`fact_error` 事实错误、`incomplete` 内容不完整、`other` 其他。
- “其他”必须填写 1-200 字说明；未填写不允许提交。
- 接口：
  - `POST /api/sessions/{session_id}/messages/{message_id}/feedback`
  - `DELETE /api/sessions/{session_id}/messages/{message_id}/feedback`
- 幂等：唯一约束 `(message_id, user_id)`；重复提交更新；并发冲突返回最新状态。
- 返回：当前用户 rating、reason_code、reason_text、该消息 like/dislike 计数。
- 历史回显：`GET /api/sessions/{id}/messages` 的每条消息增加 `feedback` 字段（当前用户评价 + 计数）。
- trace 关联：feedback 表存 `trace_id`，后台可从评价跳转调用链。
- 安全：reason_text 仅文本渲染；长度 200；禁止 `v-html`。

### 6.5 管理后台

#### 6.5.1 路由与访问

- 前端 `/admin` 使用 vue-router，用户页 `/`；后台路由懒加载。
- 本地不鉴权；页面顶部固定提示“仅限本地使用，公网部署前必须加鉴权”。
- 后端 `/api/admin/*`；默认仅 127.0.0.1 可访问；CORS 沿用现有 localhost:5173。
- 本期不新增登录、不新增用户体系。

#### 6.5.2 时间范围

- 顶部日期范围选择器；默认最近 7 天；最大 90 天；时区 Asia/Shanghai。
- 所有指标、明细、告警、导出共享同一范围。
- 非法范围或超过 90 天返回 400 并提示。

#### 6.5.3 总览

- 卡片：会话数、总轮次、任务型轮次、工具调用总数、工具成功率、平均轮次耗时、P95 轮次耗时、总 token、赞/踩/满意率、告警数。
- 趋势图：按天/小时展示轮次、工具成功率、满意率、P95；范围 ≤ 2 天按小时，否则按天。
- 图表用 ECharts，仅后台路由加载。

#### 6.5.4 工具维度

- 表字段：工具名、调用数、成功、失败、blocked、成功率、平均耗时、P95、重试次数、Top 3 失败原因。
- 成功率 = `ok / (ok + error)`；blocked 不计入分母，单列。
- 点击行按该工具筛选明细。

#### 6.5.5 模型维度

- 表/图：各层（deepseek/qwen/local）调用次数、成功/失败、降级次数、熔断次数、半开探测成功/失败、平均耗时、token 用量。
- 数据源：`model_success`、`model_degrade`、`breaker_open`、`breaker_skip`、`model_transient_failure`、`model_permanent_failure`、`breaker_half_open`、`breaker_probe_success`、`breaker_probe_failure`。
- 需在网关补充半开探测成功/失败事件。

#### 6.5.6 上下文维度

- 压缩次数、压缩前后 token 平均值/总量、预算收束次数、30 轮触顶次数、native 切换次数。
- 数据源：`context_compress`、`messages.meta.kind/reason`、`mode_switch`。

#### 6.5.7 会话维度

- 会话数、平均任务轮次、任务轮次分布（1-5 / 6-10 / 11-20 / 21-30 / 30+）、30 轮触顶会话数、native 会话数。
- 数据源：`sessions`、`messages`。

#### 6.5.8 满意度

- 总评价数、赞、踩、满意率 = `like / (like + dislike)`；无评价不计入分母。
- 趋势图；7 类原因分布；按工具交叉、按模型层交叉。
- 交叉口径：以 turn 为单位；该 turn 调用过某工具即计入该工具组；分母为“含该工具且有评价的 turn 数”；一条评价可计入多个工具组。
- 模型层取最终回答 `message.meta.layer`；缺失时取该 turn 最后一条 `model_success` 的 layer。
- 明细可跳转 turn。

#### 6.5.9 调用链明细

- 列表字段：时间、session_id、turn_no、trace_id、用户输入摘要、最终回答摘要、模型层、工具链（名称/状态/耗时）、总耗时、token、评价。
- 筛选：session_id、工具名、工具状态、是否有评价、finish_reason、trace_id。
- 分页 50，按时间倒序。
- 点击行进入详情：
  - 顶部摘要：turn、trace、模型层、耗时、token、评价；
  - 消息列表：用户/助手/工具；
  - 工具调用列表：参数、状态、重试、耗时、摘要、错误、result_ref；
  - trace 时间线：按 ts 排序，按 parent_span_id 树形缩进；每个 span 显示 kind、span_id、parent、duration_ms、payload 摘要；payload 可展开 JSON（截断 2000 字）；
  - 支持复制 trace_id 与跳转 `/api/traces/{trace_id}` 原始 JSON。

#### 6.5.10 异常告警

- 查询时计算，不做后台定时任务；顶部红色告警条，逐条列出规则、当前值、阈值、窗口；点击筛选明细。
- 告警固定看最近 1 小时，不受页面日期范围影响；点击告警将页面范围切到最近 1 小时。
- 默认规则（可通过环境变量覆盖）：
  1. 近 1 小时工具失败率 > 20% 且调用数 ≥ 10；
  2. 近 1 小时满意率 < 70% 且评价数 ≥ 5；
  3. 近 1 小时 P95 轮次耗时 > 60s 且轮次 ≥ 10；
  4. 近 1 小时熔断次数 ≥ 1；
  5. 近 1 小时预算收束或 30 轮触顶次数 ≥ 3。
- 仅后台展示，不发外部通知。

#### 6.5.11 CSV 导出

- 导出当前筛选的 turn 明细；UTF-8 BOM；最多 10,000 行；超出提示缩小范围。
- 字段：时间、session_id、turn_no、trace_id、用户输入、最终回答、模型层、工具链、工具状态、轮次耗时、token、评价、原因。
- 防注入：以 `= + - @` 开头的单元格前置单引号。
- 文件名 `agent-turns-{start}-{end}.csv`。

## 7. 数据模型变更

### 7.1 新表 `message_feedback`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | UUID PK | 主键 |
| message_id | UUID FK messages.id ON DELETE CASCADE | 被评价的最终回答 |
| session_id | UUID FK sessions.id ON DELETE CASCADE | 会话归属 |
| user_id | varchar(64) | 用户 |
| rating | varchar(8) | like / dislike |
| reason_code | varchar(32) nullable | 7 类原因 |
| reason_text | varchar(200) nullable | “其他”说明 |
| trace_id | varchar(64) nullable | 关联调用链 |
| created_at | timestamptz | 创建时间 |
| updated_at | timestamptz | 更新时间 |

约束与索引：

- `UNIQUE(message_id, user_id)`；
- 索引 `(session_id, created_at)`、`(rating, created_at)`、`(reason_code)`。

### 7.2 `tool_calls` 新增

- `result_meta JSONB NOT NULL DEFAULT '{}'`：存放 citations、reachable 统计、checked_at 等。
- 索引 `(created_at)`，支持时间范围查询。

### 7.3 其他索引

- `events(kind, ts)`：按事件类型聚合。
- `message_feedback(message_id, user_id)` 唯一索引。
- 旧数据 `result_meta` 为空对象；前端按空引用处理。

### 7.4 清理

- 提供 `scripts/prune_events.py --days 90` 手动清理脚本；本期不做定时任务。
- events 默认保留 90 天；清理不影响 messages/tool_calls/feedback。

### 8.1 现有接口调整

| GET | `/api/tools` | 每项新增 `online: bool` |
| POST | `/api/sessions/{id}/messages` | SSE `tool_result` 新增 `citations` 数组；仅 search 返回 |
| GET | `/api/sessions/{id}/messages` | 每条消息新增 `feedback` 对象（当前用户评价 + like/dislike 计数） |

`citations` 项字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | citation 唯一标识 |
| title | string | 标题，≤200 字符 |
| url | string | 仅 http/https，≤2048 字符 |
| snippet | string | 摘要，≤300 字符 |
| reachable | boolean | 是否通过可达校验 |
| status_code | integer/null | 最终状态码 |
| checked_at | string/null | ISO 8601 校验时间 |

### 8.2 新增用户侧接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/sessions/{id}/tool-calls` | 按会话返回工具调用，可选 `turn_no` |
| GET | `/api/sessions/{id}/tool-calls/{tool_call_id}/result` | 返回完整结果全文，校验会话归属 |
| POST | `/api/sessions/{id}/messages/{message_id}/feedback` | 新增/更新评价 |
| DELETE | `/api/sessions/{id}/messages/{message_id}/feedback` | 取消评价 |
| POST | `/api/citations/check` | 按 citation_ids 重新校验，仅限当前会话已存引用 |

评价请求字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| rating | string | like / dislike |
| reason_code | string/null | 7 类原因编码，点赞时为空 |
| reason_text | string/null | “其他”说明，1-200 字 |

评价响应字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| message_id | string | 被评价消息 |
| rating | string | 当前用户评价 |
| reason_code | string/null | 原因编码 |
| reason_text | string/null | 其他说明 |
| likes | integer | 该消息点赞数 |
| dislikes | integer | 该消息点踩数 |
| updated_at | string | ISO 8601 更新时间 |

### 8.3 新增后台接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/admin/metrics?start=&end=` | 总览、趋势、工具、模型、上下文、会话、评价、告警 |
| GET | `/api/admin/turns?start=&end=&page=&page_size=&session_id=&tool_name=&tool_status=&rating=&finish_reason=&trace_id=` | 调用链列表 |
| GET | `/api/admin/turns/{trace_id}` | 单 turn 详情：摘要、消息、工具调用、events |
| GET | `/api/admin/export?start=&end=&...` | 当前筛选 CSV |

约束：

- `start/end` 为 ISO 8601；最大跨度 90 天；`start < end`。
- `page_size` 默认 50，最大 200。

## 10. 指标口径

| 指标 | 口径 |
|---|---|
| 轮次 | 以 `turn_no` 为单位；任务型轮次 = 该 turn 至少 1 次工具调用 |
| 工具成功率 | `ok / (ok + error)`；blocked 单列，不计入分母；参数/Schema 错误计 error |
| 工具平均耗时 | `tool_calls.latency_ms` 平均值 |
| 工具 P95 | 将耗时升序排列，取第 95 百分位 |
| 轮次耗时 | `events.kind=turn` 的 `duration_ms`；缺失时用该 turn 首末消息时间差 |
| 满意率 | `like / (like + dislike)`；无评价不计入分母 |
| 模型层 | 最终回答 `message.meta.layer`；缺失取该 turn 最后一条 `model_success` |
| Token | `message.meta.usage.total_tokens`；缺失用 prompt+completion；再缺失不计 |
| 降级次数 | `events.kind=model_degrade` 计数 |
| 熔断次数 | `events.kind=breaker_open` 计数 |
| 半开探测 | `breaker_half_open`、`breaker_probe_success`、`breaker_probe_failure` 计数 |
| 压缩次数 | `events.kind=context_compress` 计数 |
| 预算收束 | `messages.meta.kind=budget_exceeded` 或 `wrap_up.reason=budget_exceeded` |
| 30 轮触顶 | `messages.meta.kind=wrap_up` 且 `reason=max_task_turns`；或 `sessions.status=wrapped` |
| native 切换 | `events.kind=mode_switch` 计数 |
| 告警窗口 | 固定最近 1 小时，不受页面日期范围影响 |
| 趋势粒度 | 范围 ≤ 2 天按小时，否则按天 |
| 时区 | 展示 Asia/Shanghai；存储 UTC |

## 11. 异常与边界

| 场景 | 处理 |
|---|---|
| MCP 离线 | 工具面板全部离线；聊天沿用现有错误提示；不崩溃 |
| search 无 citations | 无引用区；工具汇总仍显示 search 状态 |
| 所有链接校验失败 | 显示“未获取到可访问来源”，失败链接折叠 |
| 链接校验超时 | `reachable=false`，标注超时；不阻塞 search 成功 |
| SSRF 尝试 | 拒绝并记录 `link_check_rejected`；不发起请求 |
| 评价非最终消息 | 400 |
| 评价重复提交 | upsert；唯一约束兜底；返回最新状态 |
| “其他”未填说明 | 422 |
| 原因编码非法 | 422 |
| 后台范围 > 90 天 | 400 |
| 后台无数据 | 空态，不报错 |
| CSV > 10,000 行 | 400，提示缩小范围 |
| trace 不存在 | 404 |
| tool_call 结果不存在 | 404 |
| 旧数据无 result_meta/feedback | 空引用、无评价；前端隐藏对应区域 |
| 并发评价 | 捕获 IntegrityError 后重查返回 |
| SSE 重连 | 引用随 tool_result 回放；评价从历史接口回显 |
| 多次 search | 合并去重，最多 10 条 |
| 同名工具多次调用 | 按 tool_call_id 分别展示，不合并 |
| 引用 URL 去重 | 协议/域名小写，去 fragment，保留 query |
| 标题/摘要含 HTML | 纯文本渲染；后端截断 |
| 文件/私网 URL | 校验前直接拒绝 |

## 12. 安全与风险

| 风险 | 影响 | 处置 |
|---|---|---|
| 后台无鉴权 | 本地可用，公网暴露即数据泄露 | 默认仅 127.0.0.1；页面提示；公网部署前必须加鉴权（P1） |
| 链接校验 SSRF | 服务端被诱导访问内网 | citation id 白名单、私网 IP/域名拒绝、重定向二次校验、DNS 检查、仅 http(s)、最多 10 条 |
| 链接校验被反爬误杀 | 正常链接标失败 | 标记“未通过校验”而非“失效”；点击兜底再验 |
| 校验拖慢 search | 最坏 +8 秒 | 并行校验、单条 8 秒、并发 5；用户已确认接受 |
| events 增长 | 后台聚合变慢 | 时间/类型索引；90 天保留；手动清理脚本；查询最大 90 天 |
| ECharts 包体 | 首屏变慢 | 仅后台路由懒加载 |
| CSV 公式注入 | Excel 执行恶意公式 | `= + - @` 开头前置单引号 |
| XSS | 评价/标题/摘要注入 | 不使用 v-html；URL 仅 http(s)；外链 noopener |
| 旧数据缺失 | 后台/前端空值 | 空对象兼容；不回溯 |
| 过程卡片与末尾汇总重复 | 视觉冗余 | 汇总默认折叠；过程卡片保持紧凑；按 tool_call_id 去重 |
| 告警误报 | 样本不足 | 每条规则带最小样本量阈值 |
| 评价刷量 | 单用户重复提交 | 唯一约束 + upsert；本期固定 dev-user |
