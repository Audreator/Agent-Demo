# 开发提示词：工具可视化、引用可信度与管理后台（T26102201）

## 0. 先读文档

- `tasks/v0.1/T26102201_需求概括.md`：唯一需求来源，参见此文档。
- `tasks/v0.1/T26102201_示例代码.md`：参考片段，不是最终代码。
- 冲突以需求文档为准。**不要调用 Audreator-req 技能**，直接开发。

## 1. 目标

在现有最小 Agent 上增量实现：

1. 用户页左侧栏展示 5 个在线工具及状态。
2. 回答末尾展示本轮工具汇总，点击展开参数/结果/耗时；纯聊天不显示。
3. 搜索引用只展示真实可访问链接，默认 3 条，可展开全部，点击前再校验。
4. 新增本地管理后台：自定义时间范围的调用链、工具成功率、满意率、模型/上下文指标、异常告警、CSV 导出。
5. 最终回答底部点赞/拉踩，7 类原因，可改可取消。

## 2. 硬约束

- 沿用 Python 3.11+ / FastAPI / httpx / SQLAlchemy async / PostgreSQL；Vue 3 / Vite / TS / Pinia。禁 React、Agent 框架、MCP SDK。
- 新增前端依赖仅 `vue-router` 4.x、`echarts` 5.x；ECharts 仅后台路由懒加载。
- 不改现有 MCP 协议、SSE 事件名、现有 API 字段，只做增量。
- 后台本地不鉴权，`/admin`；后端默认仅 127.0.0.1，不得 0.0.0.0；页面提示公网部署前必须加鉴权。
- 新接口必须校验 `session_id + user_id`，禁止跨会话读取。
- 链接校验防 SSRF：只接受当前会话已存 citation id，拒绝私网 IP、localhost、非 http(s)、重定向到私网、DNS 私网；最多 10 条。
- 链接校验失败不得让 search 失败，只标 `reachable=false`。
- 前端禁 `v-html`；外链仅 http/https，新窗口打开并带 noopener noreferrer。
- CSV 防公式注入：`= + - @` 开头前置单引号。
- DB 存 UTC，界面 Asia/Shanghai。
- 数据量 <1000 轮/天；events 保留 90 天；后台查询最大 90 天；分页 50。

## 3. 后端

### 3.1 数据层

- 新表 `message_feedback`：id、message_id、session_id、user_id、rating、reason_code、reason_text(200)、trace_id、created_at、updated_at；唯一 `(message_id,user_id)`；索引 `(session_id,created_at)`、`(rating,created_at)`、`(reason_code)`。
- `tool_calls` 新增 `result_meta`（JSONB，默认空对象），存 citations 与可达状态。
- 新增索引 `events(kind,ts)`、`tool_calls(created_at)`；写 Alembic 迁移。
- 提供 `scripts/prune_events.py --days 90` 手动清理脚本，不做定时任务。

### 3.2 在线工具

- `GET /api/tools` 每项新增 `online`：MCP 子进程存活且 `tools/list` 成功则全部在线，否则全部离线。不做逐工具探活。

### 3.3 搜索引用

- `search` 内归并、去重、最多 10 条；URL 规范化（协议/域名小写、去 fragment、保留 query、≤2048）。
- 并行校验：先 HEAD，400/403/405/429 或异常改 GET（带 Range 头只读前 2KB，读完关闭）；跟随重定向；单条 8 秒；并发 5。
- 最终 2xx/3xx 且未超时 => 可达；401/403/404/5xx/超时 => 不可达。
- 校验前做 SSRF 检查；任一失败不影响 search 成功；结果写入 `tool_calls.result_meta`。
- SSE `tool_result` 新增 `citations`，字段为 id、title、url、snippet、reachable、status_code、checked_at；仅 search；title ≤200、snippet ≤300。
- 新增 `POST /api/citations/check`，body 为 citation_ids 数组；只允许当前会话已存 id；LRU 缓存 10 分钟、最多 500 条。

### 3.4 工具明细

- blocked 工具必须落 `tool_calls`，`status=blocked`。
- 新增 `GET /api/sessions/{id}/tool-calls?turn_no=`：返回参数、状态、重试、耗时、摘要、result_ref、error、result_meta。
- 新增 `GET /api/sessions/{id}/tool-calls/{tool_call_id}/result`：返回全文，校验会话归属，缺失 404。
- `GET /api/sessions/{id}/messages` 每条消息新增 `feedback`：当前评价 + like/dislike 计数。

### 3.5 评价

- `POST /api/sessions/{id}/messages/{message_id}/feedback`；只允许 assistant 且 meta.kind 为 final 或 wrap_up。
- 7 类原因：irrelevant、tool_error、bad_link、too_slow、fact_error、incomplete、other；other 必填 1-200 字，否则 422。
- 同一用户同一消息唯一，重复提交 upsert；`DELETE` 取消；并发 IntegrityError 后重查返回。
- `trace_id` 从 message.meta 或 session.last_trace_id 取。

### 3.6 后台

- `GET /api/admin/metrics?start=&end=`：overview、trend、tools、models、context、sessions、satisfaction、alerts。
- `GET /api/admin/turns?...`：分页 50、时间倒序，支持 session、工具、状态、评价、finish_reason、trace 筛选。
- `GET /api/admin/turns/{trace_id}`：summary、messages、tool_calls、events。
- `GET /api/admin/export?...`：CSV，UTF-8 BOM，最多 10,000 行。
- ISO 时间；最大 90 天；start<end；越界 400；按 dev-user 限定。
- 指标口径严格按需求文档第 10 节；工具成功率 `ok/(ok+error)`，blocked 单列；满意率 `like/(like+dislike)`。
- 网关补 `breaker_half_open`、`breaker_probe_success`、`breaker_probe_failure` 事件。
- 告警查询时计算，固定近 1 小时，5 条规则与阈值按需求文档；顶部红条，点击筛选。
- 趋势：范围 ≤2 天按小时，否则按天。

## 4. 前端

- vue-router：`/` 聊天页，`/admin` 后台，后台懒加载；新增入口与返回聊天。
- 左侧栏 `ToolPanel.vue`：折叠、5 工具、在线点、描述、手动刷新、30 秒轮询。
- `ToolSummary.vue`：回答末尾汇总；折叠显示工具数/成功/失败/禁用/总耗时/来源数；展开显示参数、状态、耗时、重试、摘要、错误、artifact 引用与“查看完整结果”；纯聊天不渲染。
- `CitationList.vue`：末尾、工具汇总下方；默认 3 条；展开全部；失败链接折叠灰色不可点；标题/域名/snippet/可达标识；点击前调 `/api/citations/check`，2 秒超时直接打开；无可用链接显示空态。
- `FeedbackBar.vue`：最终回答底部赞/踩；踩弹 7 类原因；other 必填；可取消/切换；历史回显。
- 历史消息加载 `tool-calls` 与 `feedback`，按 turn 分组；无数据不渲染。
- SSE 解析 `tool_result.citations`；断线重连从 replay 恢复。
- `AdminView.vue` + `TurnDetail.vue`：日期范围、告警条、总览卡片、ECharts 趋势、工具/模型/上下文/会话/评价表、筛选分页、trace 树、payload 展开、CSV、空态/加载态/错误态。
- ECharts 仅后台 chunk；不引入 UI 框架；沿用现有 CSS 变量。

## 5. 测试与验收

- 单元：链接校验（200/301/403/404/超时/私网/DNS 私网/重定向私网/file/超 10 条）、引用归并、评价校验与 upsert、指标公式、告警阈值、CSV 转义、旧数据兼容。
- 集成：search citations 且链接失败不影响成功；SSE citations；tool-calls 与完整结果；评价回显；后台 metrics/turns/detail/export；blocked 落库；SSRF 拒绝；90 天限制。
- e2e：真实 search 至少 1 条可达，网络失败可跳过。
- 回归：`ruff check .`、`mypy app`、`pytest -q` 全通过；现有 68 个测试不退化。
- 前端：`npm ci`、`npm run typecheck`、`npm run build` 全通过。

## 6. 禁止

- 禁止假数据、硬编码统计结果、跳过测试。
- 禁止把客户端任意 URL 交给服务端请求。
- 禁止链接校验失败导致 search 失败。
- 禁止破坏现有 API/SSE/数据库字段。
- 禁止默认监听 0.0.0.0，禁止给后台加临时公网无鉴权入口。
- 禁止 React、Agent 框架、MCP SDK、UI 框架。
- 禁止未跑通测试与构建就宣称完成。
